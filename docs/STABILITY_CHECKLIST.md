# Checklist de estabilidad

Antes de considerar una versión lista para producción:

- [ ] Vercel Preview en verde.
- [ ] Portada revisada en ordenador.
- [ ] Portada revisada en tablet.
- [ ] Portada revisada en móvil.
- [ ] Reserva de valoración probada.
- [ ] Ver tarifas probado.
- [ ] Login administrador probado.
- [ ] Login cliente probado.
- [ ] Correos transaccionales probados.
- [ ] Eventos y recordatorios probados.
- [ ] Exportación Excel probada.
- [ ] Sin secretos añadidos al repositorio.
- [ ] Backup reciente disponible antes de migraciones importantes.

Si cualquiera de los puntos críticos falla, no fusionar a `main`.
