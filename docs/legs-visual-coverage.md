# Cobertura visual de Piernas

La biblioteca visual de Piernas incluye representación propia Chetesaí para los códigos CHE-PIE-001 a CHE-PIE-021 existentes, con estados Inicio/Ejecución y variantes específicas para sentadillas, zancadas, bisagras, prensa, extensión, curl femoral, trabajo unilateral y gemelos.
