# Changelog

## v1.0.0 — 2026-08-07

Primera versión estable de producción de Chetesaí Fitness+.

### Incluye
- Landing responsive para ordenador, tablet y móvil.
- Menú lateral móvil y navegación por secciones.
- Reserva de valoración con envío de correo.
- Acceso privado de clientes.
- Gestión de clientes, rutinas, ejercicios y seguimiento.
- Portal cliente con sesiones, progreso e historial.
- Informes financieros y exportación Excel.
- Pagos y membresías.
- Eventos y comunidad con invitaciones y recordatorios.
- Perfil profesional y documentación pública.
- Modal de tarifas responsive.

### Punto estable
- Commit de aplicación: `dd4cef265c9cc028e8105dcec9eb8dccf66bc3ed`
- Rama de recuperación: `release/v1.0.0`
- Producción: `main` → Vercel → `chetesaifitness.com`

### Política de cambios
A partir de esta versión, los cambios funcionales deben hacerse en ramas `feature/*` o `fix/*`, validarse en Vercel Preview y fusionarse a `main` mediante Pull Request.
